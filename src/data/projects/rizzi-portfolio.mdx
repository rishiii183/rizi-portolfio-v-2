# RIZZI Portfolio — Modern Portfolio for Creative Professionals

## Overview

Designed and developed a bespoke interactive portfolio to showcase creative digital products, thumbnail design, and engineering case studies with high-converting elegance.

## Key Features

- **Interactive Gallery & Showcases**: Immersive layout transitions with fluid hover previews and modal views.
- **Micro-Animations**: Framer Motion gesture feedback, custom cursor interactions, and sound effects.
- **Responsive Engineering**: Fully optimized across desktop, tablet, and mobile breakpoints.
- **60 FPS Animation Standards**: Composite-only transforms ensuring butter-smooth interactions.

## Tech Stack

- React & TypeScript
- Vite
- Framer Motion
- Tailwind CSS
- Lenis Smooth Scroll
