# Lume (DebtRadar) — AI-Powered Security & Technical Debt Platform

## Overview

Lume is an engineering intelligence platform designed to help security engineers, tech leads, and managers monitor systemic vulnerabilities, technical debt, and compliance obligations in real-time.

## Key Features

- **Interactive Vulnerability Mapping**: Visual dependency graph powered by D3.js mapping out security debt and high-risk modules.
- **AI-Assisted Remediation**: Automated mitigation suggestions powered by fine-tuned Mistral 7B models.
- **Continuous Compliance Tracking**: Automated auditing against OWASP Top 10 and common security frameworks.
- **Enterprise Dashboard**: Sleek dark-mode interface built on Next.js 14, TypeScript, and Supabase database authentication.

## Tech Stack

- Next.js & React
- TypeScript & Tailwind CSS
- D3.js Interactive Data Visualizations
- Supabase (PostgreSQL & Auth)
- Mistral 7B & HuggingFace
- GitHub REST & GraphQL APIs
