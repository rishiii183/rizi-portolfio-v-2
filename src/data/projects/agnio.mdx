# Agnio — Creative Agency & Digital Experience Website

## Overview

Agnio is a modern creative agency platform engineered to deliver world-class web design, brand identities, and immersive digital experiences. Built with performance and aesthetics at the core.

## Key Features

- **Fluid Momentum Scrolling**: Smooth inertia-based scrolling powered by Lenis.
- **Micro-Interactions & Transitions**: Cohesive enter, hover, and reveal animations crafted with Framer Motion.
- **Editorial Typography**: Elegant layout architecture prioritizing readability, contrast, and visual hierarchy.
- **Production Performance**: Sub-second load times optimized on Vite with zero layout shifts.

## Tech Stack

- React & Vite
- Framer Motion & CSS Animations
- Lenis Smooth Momentum Scroll
- Tailwind CSS & Lucide Icons
- Vercel Edge Network
