# ResearchOS — Autonomous Multi-Agent AI Research Platform

## Overview

ResearchOS is an autonomous multi-agent research platform designed to automate deep information gathering, cross-referencing, web scraping, and executive synthesis. By chaining specialized agents with distinct research responsibilities, it generates structured intelligence briefs with verified citations.

## Key Architecture

- **Agent Orchestration**: Built on LangGraph to coordinate planner, search, scraper, verification, and synthesis agents into a directed acyclic workflow.
- **Ultra-Fast LLM Inference**: Powered by Groq-hosted Llama 3.3 70B for near-instant sub-second agent deliberation.
- **Deep Web Retrieval**: Multi-source scraping pipeline using Tavily Search API and BeautifulSoup4 with intelligent fallback retry logic.
- **Streaming UI**: Real-time agent status feeds and generated reports rendered with React 19, Vite, and Framer Motion.
